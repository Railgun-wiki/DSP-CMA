# DSP-CMA 课程大作业实验报告

本报告全部数字来自 `results/<run_id>/` 保存的真实运行结果（配置、数据哈希、机器可读指标与日志），可按 §10 的命令复现。需求原文与勘误见 [requirements.md](requirements.md)，设计细节见 [architecture.md](architecture.md)，验证状态与命令见 [validation.md](validation.md)。

## 1. 问题与要求

基础任务（80%）：MATLAB 自编 32/128 点 FFT（模拟硬件并行结构）、基于自编 FFT 的超数据流快速卷积（FFT→频域相乘→IFFT，信号与滤波器用户可指定）、双偏振频域 CMA 均衡（利用快速卷积完成梯度更新）、修改抽头长度分析均衡效果。进阶任务（20%）：Verilog 全并行 32/64 点 FFT，实部虚部各 8 bit，乘法用 3 拍延迟的乘法器 IP/原语，不用厂商 FFT IP，在 xcvu13p-flga2577-2-i 于 250 MHz 下运行 Implementation。勘误：CMA 评估用 **EVM，不计算 BER**。

## 2. 原理与设计要点

- **FFT**：基-2 DIT，输入位倒序、输出自然序；按级计算模拟硬件全并行结构（各级蝶形索引见 [architecture.md](architecture.md) §1.2）。旋转因子手工生成：仅 `floor(M/4)+1` 次基础角调用，二象限共轭对称、后半周期反对称、倍角递推扩展，特殊因子 1/-1/1j/-1j 置精确值。IFFT 用共轭关系实现，末端除 N。
- **快速卷积**：OLA（整块卷积累加，尾部 L-1 重叠区）与 OLS（历史区+有效区，末块补零冲刷）；约束 `N ≥ B+L-1`；信号与滤波器由使用者指定（`conv_demo`）。
- **频域 CMA**：2×2 蝶形均衡器四支路（抽头不取共轭）；每段 32 点用 OLS 滤波，梯度相关 `IFFT(fft(mu·e·z)·conj(X))` 直接给出各抽头梯度（bin 与相对时刻一一对应，无循环污染）；每 4 段累积梯度除以 4 更新，下一时钟生效（clk_dly=1）。
- **DD-EVM**：数据无已知发送符号，校准（四次方相位 + 模增益，独立段估计冻结）后判决到最近理想 4QAM 点计算 EVM。
- **RTL**：每级 N/2 个蝶形实例全并行，DSP48E2 原语 3 拍乘法，每级 1/2 缩放半偶舍入，输出 = round(FFT(x)/N)，总延迟 22/26 拍。

## 6. 信道特性与结果解释（重要）

均衡后星座为**等模圆环**（|z|² ≈ 1.93，相位均匀分布）。诊断证据（`phase_diagnosis.png`、`metrics_phase_diagnosis.json`）：

1. 原始数据 4QAM 相位相干度 `|E[x⁴]|/E[|x|⁴]` = 0.0149（X）/ 0.0092（Y）≈ 0 —— **逐符号相位均匀随机**；折叠相位直方图均匀（std ≈ 0.454），逐样本散点在整个记录上无漂移、无块结构；
2. LTI 均衡器不可能把"相位相干"的输入变为"相位随机"的输出，故该相位随机化存在于原始数据（信道自带强载波相位噪声/相位加扰）；
3. 等模圆环 + 均匀相位对 4QAM 判决的解析 DD-EVM 下限为 **44.65%**（推导见 [architecture.md](architecture.md) §5）。实测均衡后 45.65～45.94%，**距理论下限仅 +1.0～1.3 个百分点** —— CMA 已把可消除的线性损伤（ISI）移尽；
4. 均衡前为无结构圆盘（ISI + 相位随机叠加），均衡后模值收敛到 R=2 且两偏振独立（ρ≈0.007）——CMA 完成了其设计目标内的全部工作。

**结论**：均衡效果差异体现在"超出圆环下限的 ISI 残余"上（+1.0～+1.3%）；残余 DD-EVM 的主体（44.65%）由数据集的相位随机化决定，超出 CMA（对相位盲）的能力范围，需要载波相位恢复才能进一步降低——这超出课程要求的 CMA 任务范围。

## 7. 抽头长度影响分析（B06）

| 抽头 | N_fft | 超出圆环下限（X/Y，百分点） | 收敛末值 CMA 代价（两偏振和） |
| --- | --- | --- | --- |
| 17 | 64 | +1.02 / +1.00 | 0.332 |
| 33 | 64 | +1.04 / +1.00 | 0.332 |
| 65 | 128 | +1.29 / +1.21 | — |

- 17 与 33 抽头效果几乎相同（差 < 0.05 个百分点）：信道残余 ISI 很小，33 抽头已充分；
- 65 抽头略差（+0.25 个百分点）：更多自由度在相位随机化的数据上拟合噪声，收敛更慢（运行时间 ~2 倍）；
- 所需 FFT 长度随抽头增加（64→128），计算量按 N log N 增长；
- 结论：在本数据集上 **17/33 抽头优于 65 抽头**；抽头长度的影响体现在"ISI 残余 + 收敛速度 + 计算量"三者，而非 DD-EVM 绝对值（后者被相位随机化下限主导）。

## 8. 定点与 RTL 结果（进阶任务）

- **定点模型 vs 浮点**：随机用例最大绝对误差 0.699 LSB（FFT/N 口径）；12 用例 × 8 帧向量与期望由 `fft_fixed_model` 逐位生成，manifest 含 SHA-256。
- **RTL 功能仿真（Verilator 5.054，`scripts/run_verilator.sh`）**：
  - 乘法器：2000 组随机 16×16 有符号乘积逐位一致，延迟恰 3 拍，en 门控与复位清零通过；
  - 蝶形：特殊因子旁路（±1/±1j）、普通复乘、半偶舍入恰半情形、顶/底臂符号、延迟 4 拍、冻结保持全部通过；
  - FFT32：6 用例 × 8 帧与 MATLAB 定点模型**逐位一致**，首帧延迟恰 22 拍，气泡流与中途复位通过，无陈旧输出，sat_cnt=0；
  - FFT64：同上，延迟 26 拍。
- **Vivado 仿真与 Implementation（H05 仿真部分 / H06）**：本机无 Vivado，状态 **BLOCKED**；可重建 Tcl 已交付（`scripts/vivado/`），补跑命令见 [validation.md](validation.md)。综合源码经规则检查确认无数据通路 `*`、无 IP 依赖、无仿真构造。

## 9. 局限

1. **相位随机化数据**：DD-EVM 的 44.65% 下限由数据集决定；本作业的 CMA 无法也不应伪造更低的数值。
2. **Vivado 环节 BLOCKED**：xsim 仿真、综合、Implementation、资源/时序数据需补跑；补跑脚本已交付但未执行，故无任何虚构的资源/Fmax 数字。
3. `clk_dly ≠ 1` 的抽头更新队列未实现（参考代码本身在该参数下语义存疑），按 AGENTS 口径显式拒绝。
4. 引脚约束为合成选择（无实板），Implementation 的 IO 时序无真实板级意义。
