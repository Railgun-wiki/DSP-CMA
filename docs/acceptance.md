## 必须整改的发现

### F01 · P1 · 综合 DSP48E2 包装无法对接真实原语

位置：`rtl/common/dsp_mult3.v:35`、`:38`、`:39`、`:45`。

包装实例连接 `.CE(en)`、`.RST(rst)`，而真实 DSP48E2 使用独立的 `CEA1/CEA2/CEB1/CEB2/CEM/CEP` 等使能和 `RSTA/RSTB/RSTM/RSTP` 等复位端口；官方声明没有 `CE`、`RST`。将原版官方声明提取后与包装联合 lint，得到两个 `PINNOTFOUND` 错误。此外 `USE_MULT("MULTIPLIER")` 不在原语合法枚举中，官方使用 `MULTIPLY`；`D` 和 `OPMODE` 也分别应核对为 27 bit 和 9 bit。依据为 [Xilinx 官方 DSP48E2 源码](https://github.com/Xilinx/XilinxUnisimLibrary/blob/master/verilog/src/unisims/DSP48E2.v)。

现有 4 TB 通过时替换掉了这份综合文件，因此不能据此宣布 H04 综合实现有效。需修复完整配置、连接必需控制输入，并通过真实原语仿真重新证明 3 拍延迟、使能、复位及连续数据。

### F02 · P1 · Vivado 补跑入口含可独立复现的 Tcl 错误

位置：`scripts/vivado/common.tcl:62`、`scripts/vivado/run_sim.tcl:30`；另需复核 `run_impl.tcl:29` 的设计打开顺序。

`make_pin_constraints` 生成 `[get_ports din[0]]`，重新解析时 Tcl 把 `[0]` 当命令执行，报 `invalid command name "0"`。总线名必须按 Tcl 列表/引用规则正确保护。xsim 参数使用大括号包住 `[pwd]`，所以实际值为字面 `vectors=[pwd]/rtl/tb/vectors`，不是仓库路径，FFT TB 无法据此找到向量。两个问题均用原函数/原参数在 tclsh 中复现，未冒称运行了 Vivado。

另有静态风险：新工程尚未综合或打开 elaborated design 时就查询 `get_ports` 和封装引脚；两个顶层共用工程还会积累约束文件。应从干净工程验证，而不能将“一条命令即可完成”作为已证实事实。

### F03 · P1 · JSON 保存静默丢失结构体数组

位置：`matlab/+dspcma/+io/save_json.m:25`–`:29`。

递归函数只读取 `v(1)`。实测保存三个结构体后，重新载入只剩一个。当前 `tests_summary.json` 声称检查数合计 101，实际上每组仅保存第一项，共 8 项；`rtl/tb/vectors/manifest.json` 及定点结果也只保留 12 个用例中的首项。向量文件本身仍在，但“manifest 含逐文件哈希”的交付声明不成立。

需正确保留任意层级结构体数组、重建全部结果及 manifest，并对保存后重新载入的元素数、检查数、文件哈希做完整性断言。单独把外层 `tests`/`taps` 转成 cell 不能修复嵌套数组。

### F04 · P1 · 报告对圆环星座的因果解释超出证据

位置：`docs/report.md:59`–`:66`，同类结论也存在于 README、架构和汇报稿。

四次方全局均值接近零不能推出“逐符号独立均匀随机相位”：验收构造了仅含确定频偏的无噪声 QPSK，四次方相干度为约 `1.04e-16`，相邻四次方相关仍为 1。44.65% 是在特定等模圆环、均匀相位和增益口径下的条件计算，不能升级为该数据集不可突破的下限；EVM 百分数之差也不能直接解释为残余 ISI。

实测默认输出四次方序列的滞后 1/64/256 相关分别约为 0.724/0.735/0.731（全记录，减均值），不支持直接宣告逐符号独立相位。进一步在尾部评估窗对单位相位四次方检查，输出滞后 1 相关为 0.8476，打乱样本顺序后降至 0.00145；原始 X 对应为 0.08377 和 0.00224。去幅度后的相关仍然存在，完整检查见 `acceptance/matlab_phase.log`。这些检查用于指出证据不足，不用于擅自指定真实信道模型。

默认输出在 ±64 点延迟内最大互相关为 0.01372（延迟 43），未发现该范围内的延迟副本。现有实现只计算零延迟相关；随机序列及其延迟副本可得到零延迟相关 0.00564、对齐后相关 1，所以不能以一个零延迟数字证明成功解复用。

需保留已证实的 DD-EVM 改善和模值统计；将信道类型、相位噪声、ISI 已移尽等因果结论改为待验证假设，补充适当证据后再下结论。
