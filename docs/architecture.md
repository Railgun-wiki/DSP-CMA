# 架构与设计决策

本文档冻结算法公式、索引约定、定点方案、RTL 结构与关键工程决策（ADR）。所有数字与表格对应仓库当前实现；变更须同步更新。

## 1. 自编 FFT/IFFT（B01/B02）

### 1.1 约定

- 正变换：`X[k] = Σ_{n=0}^{N-1} x[n]·exp(-j2πkn/N)`；IFFT 仅在末端除以 N（`ifft(X) = conj(my_fft(conj(X)))/N`）。
- 基-2 按时间抽取（DIT）：输入位倒序重排（纯索引重排），逐级蝶形，输出自然序。支持 N 为 ≥2 的 2 的幂；强制验收 32/128 点，另支持 64/256 供卷积使用。
- 函数契约：输入输出同形状向量（行入行出/列入列出）；错误标识 `DSPCMA:fft:*`。

### 1.2 与硬件并行结构的对应

MATLAB 实现按级循环（`for s = 0..log2(N)-1`），同一级内所有蝶形一次性（向量化）完成，与 RTL 的"每级 N/2 个蝶形实例同时计算"一一对应。第 s 级（0 起）结构：

- 块长 `M = 2^(s+1)`，跨距 `half = 2^s`，每块内第 `j`（0 基）个蝶形连接位置 `b·M + j` 与 `b·M + j + half`（b 为块序号）；
- 旋转因子幂次 `m = j`，即 `W_M^j = exp(-j2πj/M)`；
- `fft_stage_map(N)` 返回各级 (pairs, tw_exponent, special) 映射，与 RTL `fft_radix2_core.v` 的 generate 布线一一对应（32 点：5 级 80 蝶形；128 点：7 级 448 蝶形）。

### 1.3 旋转因子手工计算与优化（B02）

`twiddle_table(M)` 的生成方式：

1. 基础角：仅对 `m = 0..floor(M/4)` 调用 cos/sin（`info.base_angle_calls = floor(M/4)+1`）；
2. 第二象限 `m ∈ (M/4, M/2)`：`W^m = -conj(W^(M/2-m))`；
3. 后半周期 `m ∈ [M/2, M)`：`W^m = -W^(m-M/2)`；
4. 特殊因子精确化：`m = 0, M/4, M/2, 3M/4` 直接置 `1, -1j, -1, 1j`，避免浮点噪声。

基础角调用次数（N 点 FFT 合计）：`Σ_s (2^(s-1)+1)`（例如 N=32 为 1+2+3+5+9 = 20 次；N=128 为 33 次）。验证：全索引与直接公式绝对误差 ≤ 8.0e-16（阈值 1e-12）、半周期反对称、倍角递推 `W^(2m) = (W^m)²`、共轭对称、特殊因子 isequal。

## 2. 快速卷积：OLA 与 OLS（B03/B04）

直接卷积基线 `conv_direct.m` 用显式循环实现（AGENTS 允许），全卷积语义，输出长度 `Lx + Lh - 1`。

对块长 B、滤波器长 L、FFT 长度 N（2 的幂）：**约束 `N ≥ B + L - 1`**，违反即报错 `DSPCMA:conv:badN`（循环卷积污染）。默认 `B = N - L + 1`。

### 2.1 重叠相加（OLA）索引示意（1 基）

```
输入块 b:  x[(b-1)B+1 .. bB]        （末块不足补零）
块卷积:    Y = IFFT(FFT(xb_补零) .* FFT(h_补零))，B+L-1 点有效
累加区:    y[(b-1)B+1 .. (b-1)B+B+L-2] += Y(1 : B+L-1)
           前 B 点为本块新增；尾部 L-1 点与下一块输出区重叠相加
```

### 2.2 重叠保留（OLS）索引示意（1 基）

```
FFT 缓冲:  buf = [hist(1..L-1) | cur(1..B) | 补零至 N]
           hist = 上一块末尾 L-1 个真实输入样本（首块为全零，
           与直接卷积左侧补零一致；样本不足时零置于最旧侧）
有效区:    Y(L .. L+B-1) 共 B 点 = 全局输出 y[n0 .. n0+B-1]
丢弃区:    Y(1 .. L-1) 为循环卷积污染的历史区
尾部冲刷:  输入尾部补 L-1 个零后再处理，保证末块尾部输出进入有效区
```

边界覆盖（`test_convolution.m`）：复数、非整块、`B < L-1`、单点块、单点信号、单抽头、稀疏跨块、滤波器长于信号、尾部冲刷长度与新值、空输入与非法参数错误标识。与直接卷积相对 L2 ≈ 4e-16（阈值 1e-10）。

## 3. 双偏振频域 CMA（B05）

### 3.1 语义基线（与 CMA_reference.m 逐位一致）

2×2 蝶形均衡器，四支路 FIR（抽头不取共轭，`.'` 乘法）：

```
z_x[n] = Σ_l hxx[l]·x[n-l] + hxy[l]·y[n-l]      (l = 0..L-1, 0 基延迟)
z_y[n] = Σ_l hyx[l]·x[n-l] + hyy[l]·y[n-l]
e_x[n] = Rx - |z_x[n]|²,   e_y[n] = Ry - |z_y[n]|²
累积梯度(每样本, 每支路):  acc_xx += mu·e_x·z_x·conj(x[n-l])  (xx 支路)
                          acc_xy += mu·e_x·z_x·conj(y[n-l])  (xy 支路)
                          acc_yx += mu·e_y·z_y·conj(x[n-l])  (yx 支路)
                          acc_yy += mu·e_y·z_y·conj(y[n-l])  (yy 支路)
抽头更新(每 par_num=4 段 = 1 时钟):  h ← h + acc/par_num
```

更新时序（`clk_dly=1`）：第 c 时钟的 4 段用第 c 列抽头；时钟末更新写入第 c+1 列，下一时钟生效。仅承诺 `clk_dly=1`，其他值拒绝（`DSPCMA:cma:clkDly`）。非整组尾部梯度按参考口径丢弃。初始化：对角支路中心抽头 1，交叉支路 0。`final` 语义 = 最后一个时钟实际使用的抽头（与参考 `xx(:,clk_num)` 一致）。

`cma_time_run.m` 为上述语义的函数化移植：**在全量 639616 点数据上与原版脚本逐位一致（输出与最终抽头误差 0.00e+00）**（`test_cma_reference_parity.m`）。

### 3.2 频域实现（滤波与梯度均经自编 FFT）

每段 32 点独立处理，FFT 长度 `N_fft = 2^ceil(log2(32 + L - 1))`（L=17/33/65 → N_fft = 64/64/128）。FFT 缓冲排列：

```
bin 1..32            = 当前段（相对时刻 0..31）
bin 33..32+hist_len  = 历史样本（最旧在前的自然顺序, hist(j) 的相对
                       时刻为 j-(hist_len+1)；bin 与相对时刻一一对应）
其余 bin             = 补零
```

- 滤波（重叠保留）：`Zx = IFFT(Hxx·X + Hxy·Y)`，取 bin 1..32 = 当前段输出；循环代表元映射恰好覆盖 `[-hist_len, 31]`，无污染。
- 梯度相关：`acc = IFFT(fft(a) .* conj(X))` 取 bin 1..L，其中 `a = mu·e·z`（段内 32 点）；`acc[l] = Σ_n a[n]·conj(input[n-l])` 与时域逐项对应。
- 抽头以时域向量维护，每时钟开始变换到频域（特殊单位因子由 FFT 精确值承担）。

内核验证（`test_cma_kernel.m`，阈值 1e-8）：固定随机抽头 vs 直接卷积、单次更新、20 时钟各时钟抽头快照、更新时序、非整组尾部、17/65 抽头 N_fft、clk_dly 拒绝。频域 vs 时域全长自适应后相对误差 ≤ 7e-16（远优于阈值）；全量数据上 4.7e-16。

## 4. DD-EVM 与校准（B05 验收口径）

- `EVM_rms = sqrt(Σ|s-r|² / Σ|r|²)`；百分数 = 100·EVM_rms；dB = 20·log10(EVM_rms)；零参考能量报错（`DSPCMA:evm:zeroRef`）。
- **数据无已知发送符号 → 主指标命名为判决导向 DD-EVM**：校准后样本判决到最近理想 4QAM 点（sign(I)+1j·sign(Q)，确定性）作为参考 r。不计算 BER，不写成"已知参考 EVM"。
- 校准（`calibrate_4qam.m`，仅消除盲均衡固有的标量增益与公共相位）：
  1. 相位：`θ = (angle(mean(z.^4)) - π)/4`（理想 4QAM 点满足 p⁴ = -4；π/2 残余歧义对星座与 EVM 无影响）；
  2. 增益：`g = mean(|z·e^{-jθ}|)/mean(|ideal|)`；
  3. `s = z·e^{-jθ}/g`。
- 口径冻结：校准段为评估窗之前独立 131072 点（377473..508544），评估窗为末尾精确 131072 点（508545..639616，替代参考脚本 `end-131072:end` 的 131073 点）；校准参数估计后冻结应用于评估窗；均衡前后与全部抽头配置同一口径。

## 5. 实验数据的信道特性（均衡结果解释）

实测（`channel_diagnosis.m`，证据见 results/）：

- 原始数据 4QAM 相位相干度 `|E[x⁴]|/E[|x|⁴]`：X=0.0149，Y=0.0092 —— 接近 0，即**逐符号相位均匀随机**（折叠相位直方图均匀、逐样本散点无漂移/块结构）。
- CMA（对相位盲）移除 ISI 并收敛模值：均衡前弥散圆盘（DD-EVM 55.0/54.4%）→ 均衡后等模圆环（|z|² ≈ 1.93 ≈ R=2）。
- 等模圆环 + 均匀相位对 4QAM 判决的解析 DD-EVM 下限：`EVM² = (4 - 4·E[cosΔθ])/2`，`E[cosΔθ] = sin(π/4)/(π/4)` → **44.65%**。实测均衡后 45.65/45.65%（tap=17）～45.94/45.86%（tap=65），超出下限仅 +1.0～1.3%，即 **ISI 已基本移尽，残余 DD-EVM 由数据相位随机化决定**（该特性存在于原始数据，LTI 均衡器既不能产生也不能消除它）。
- 两偏振输出复相关系数 ρ ≈ 0.007（未退化为同一路）。

## 6. 定点方案（RTL 逐位口径，冻结）

| 项目 | 口径 |
| --- | --- |
| 输入 | 8 bit 有符号整数（Q0），点 k 实部 [16k +: 8]、虚部 [16k+8 +: 8] |
| 输入 Q8 化 | `<<8` 精确，16 bit |
| 旋转因子 | Q15 16 bit：`round(w·2^15)`，非特殊因子 ∈ [-32767, 32767]；±1/±1j 特殊旁路（spec 码 1..4），旁路路径精确移位/交换且与乘法路径同为 3 拍 |
| 乘法 | 16×16 有符号整数精确 31 bit（DSP48E2：AREG/BREG/MREG=1, PREG=0 + 外层寄存 = 3 拍） |
| 复乘 | m_re = WRE·bre − WIM·bim；m_im = WRE·bim + WIM·bre（4 实乘，路径对齐） |
| 蝶形和 | a<<15 ± m，Q23，33 bit 有符号 |
| 级间缩放 | 1/2：`round_half_even(sum / 2^16)` 存回 Q8 16 bit；恰半向偶 |
| 饱和 | 各级饱和到 [-32768, 32767]，帧级计数（sat_cnt；8 bit 输入 + 每级 1/2 缩放下理论上不饱和，实测向量 sat_cnt=0） |
| 末级 | `round_half_even(Q8 / 2^8)` 饱和到 8 bit 并计数；输出语义 = `round(FFT(x)/N)` |
| 溢出计数 | sat_cnt 为"发生饱和的帧数"（含末级） |

MATLAB 整数模型 `fft_fixed_model.m` 逐位复现上述口径（含位倒序、旁路、舍入、饱和、计数），随机用例 vs 浮点 `my_fft/N` 误差 0.699 LSB。测试向量 `gen_fft_vectors.m`：32/64 点 × {冲激首位/末位, 常数, 1/4 频点整数音, 随机, 极值} × 8 帧，`.mem` 格式（每行一帧，二补码 hex），manifest 含 SHA-256。RTL 表 `fft_twiddle_tables.vh` 由 `gen_rtl_tables.m` 生成（勿手改）。

## 7. RTL 结构（H01–H04）

```
din[N·16-1:0] ─> 输入寄存(1 拍, 8→Q8, 位倒序布线)
             ─> 级 0: N/2 × bfly2 (4 拍) ─> 级 1 ─> ... ─> 级 S-1
             ─> 末级舍入 Q8→8bit + 饱和计数 (1 拍) ─> dout + out_valid
valid 链:    in_valid ─> v_shift[1..4S+2] ─> out_valid (与 dout 同拍)
```

- 全并行：每级 N/2 个 bfly2 实例同时计算，每拍进/出一帧；不用单蝶形时分复用。
- 总延迟 `L = 4·S + 2` 拍（S = log2 N；N=32 → 22，N=64 → 26），逐帧恒定；out_valid 与数据同拍对齐。
- 数据通路自由运行：气泡期处理无害垃圾并自然冲刷，valid 链单独跟踪，非法/空拍不产生有效输出；复位清空全部寄存器与 valid 链，复位后无陈旧输出（TB 三相位验证）。
- 总线格式：点 k 实部 [16k +: 8]、虚部 [16k+8 +: 8]；N=32 总宽 512 bit，N=64 为 1024 bit；输入输出均自然序。
- 乘法器：`dsp_mult3` 综合实现用 DSP48E2 原语（AREG/BREG/MREG=1, PREG=0 + 外层输出寄存 = 3 拍）；仿真用 `rtl/sim/dsp_mult3_sim.v` 行为模型（同名模块，仅仿真文件集）。不使用任何 FFT IP；无厂商 FFT IP 依赖。
- RTL 不依赖 testbench；综合源无 `*` 数据乘法、无 initial/#/real/$系统任务（`scripts/check_rules.py` 强制）。

## 8. 关键决策记录（ADR）

| # | 决策 | 依据 |
| --- | --- | --- |
| ADR-1 | 验收 oracle 用手写 O(N²) DFT（`my_dft`），不用内置 FFT | AGENTS 6.2 严格口径；内置 FFT 仅可在隔离可选测试中使用 |
| ADR-2 | MATLAB 包采用 `+dspcma/+fft` 嵌套包 | AGENTS 目录树中 `+dspcma/ fft/` 的普通子文件夹无法以 `dspcma.fft.*` 解析；嵌套 `+` 是该树的 MATLAB 正确实现 |
| ADR-3 | 频域 CMA 按段（32 点）OLS，N_fft=64/64/128 | 匹配参考"每段 32 点、每 4 段更新"语义；段内 OLS+相关的 bin 无污染证明见 §3.2 |
| ADR-4 | 评估窗精确 131072 点 + 独立校准段 131072 点 | AGENTS 4.3/4.4（替代参考 131073 点窗口）；两偏振与全部抽头同口径 |
| ADR-5 | DD-EVM 相位估计用四次方 + 模增益，冻结后跨段应用 | 盲均衡固有歧义的标量校准；π/2 残余歧义对结果无影响 |
| ADR-6 | RTL 乘法用 DSP48E2 原语而非 multgen IP | H04 允许"IP 核或原语"；原语免 IP 生成依赖，配置直接可审计 |
| ADR-7 | RTL 数据通路自由运行 + valid 单独延迟链 | 使能门控数据通路会在突发结束/气泡时丢失在途帧（实测缺陷）；自由运行下气泡期垃圾自然冲刷，满足"空拍不产生有效输出" |

| ADR-9 | 仿真乘法模型与综合原语同名、按文件集分离 | AGENTS 6.3/7：行为 `*` 只在仿真专用目录；两实现 3 拍口径一致（PREG=0 + 外层寄存） |
